# Contributing

Thank you for your interest in contributing to this repository! 

These detections were built and tested in a live Microsoft 365 environment. If you find a bug, have a tuning suggestion, or want to propose a new detection, please open an Issue or a Pull Request.

## Pull Request Process
1. Ensure your KQL query runs successfully in your own environment.
2. Map your detection to the MITRE ATT&CK framework in the header.
3. Include a brief explanation of the threat scenario and how you tuned it.
